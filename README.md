## ۱. هدف Sprint (Sprint Goal)

هدف اصلی این Sprint، طراحی و پیاده‌سازی اولیه وب‌سایت آموزش موسیقی سنتی با هدف فراهم کردن امکان مشاهده ویدیوهای آموزشی، آشنایی با سازهای سنتی و دسترسی به محصولات فروشگاه آنلاین ساز است.

**هدف این Sprint:**

فراهم کردن قابلیت مشاهده سازهای سنتی و دسترسی کاربران به ویدیوهای آموزشی موسیقی سنتی.
